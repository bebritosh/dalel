# DÄLEL — дизайн фронтенда

Спокойный, деловой, доказательный интерфейс. Никаких градиентов и эмодзи.

## Принципы
- Доверие через точность: ровная сетка, читаемый текст, честные статусы.
- Одна главная кнопка на экране. Остальные действия — вторичные.
- Плашка «Это не юридическая консультация» в шапке на каждом экране.

## Цвета (токены)
- `--bg` #F8FAFC — фон страницы
- `--surface` #FFFFFF — карточки/панели
- `--border` #E2E8F0 — границы
- `--text` #0F172A — основной текст
- `--muted` #64748B — вторичный текст
- `--accent` #0F766E — основной акцент (кнопки, ссылки, фокус)
- `--accent-hover` #115E59
- `--success` #15803D — статус «подтверждено»
- `--warning` #B45309 — статус «нужно проверить»
- `--danger` #B91C1C — ошибки
- `--highlight` #FDE68A, обводка #F59E0B — подсветка строки чека

Контраст текста к фону ≥ 4.5:1. Статусы дублируются текстом, не только цветом.

## Типографика
- Шрифт Inter (с системным фолбэком). Моноширинные цифры для сумм и дат.
- Заголовки h1 28/36, h2 20/28, тело 16/24, подпись 14/20.

## Сетка и форма
- Базовый шаг 8px (отступы кратны 8).
- Контентная ширина до 1120px, центрирование.
- Радиус карточек и кнопок 12px, инпутов 8px.
- Тени мягкие, одна ступень.

## Компоненты
- Кнопка: primary (accent, белый текст), secondary (контур). Фокус — outline 2px #0F766E.
- Статус-бейдж: зелёный «подтверждено», жёлтый «нужно проверить» — всегда с текстом.
- Токен в претензии: пунктирное подчёркивание, курсор-указатель, aria-label.
- Подсветка строки чека: прямоугольник highlight с обводкой поверх изображения.

## Адаптив
- 1440×900: две колонки (поля/хронология, текст/чек).
- 390×844: одна колонка, без горизонтальной прокрутки; чек под текстом.
