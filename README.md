# DÄLEL

Конструктор доказательной претензии по некачественному товару (Казахстан): человек загружает чек и переписку, система извлекает поля с привязкой к строкам чека, строит хронологию, показывает недостающие доказательства и собирает претензию в DOCX, где каждое число и дата подтверждены фактом.

> Прототип для хакатона SDG Impact 2026. На демо используются только синтетические данные.

## Статус
**Работает:**
- Бэкенд: загрузка файлов, OCR (из фикстур), извлечение полей с grounding, подтверждение полей, проверки V1–V4, хронология, список недостающего (M1–M5), сборка претензии, выходной guard, экспорт DOCX. Тесты: `pytest -q` → 25 passed.
- Фронтенд: три экрана (загрузка → проверка → претензия), кликабельные суммы/даты с подсветкой строки на чеке, i18n RU/EN, mock- и http-режимы. `npm run build` / `typecheck` / `lint` — зелёные.
- Сквозной сценарий проходит в браузере (mock и http).

**Не сделано / сознательно урезано:**
- OCR на демо — из разметки генератора (`*.layout.json`), а извлечение — рукописные фикстуры (`handmade_*.json`); это **не** результат реального распознавания (см. [docs/DECISIONS.md](docs/DECISIONS.md)).
- Нет: PDF-экспорта (только DOCX), Telegram-парсера (только WhatsApp), проверок V5–V8, PaddleOCR, dark mode.
- Фаза оценки точности (`eval/run_eval.py`, 8–10 дел) не реализована — есть только генератор одного демо-дела.
- Живой OCR (Tesseract) и живой LLM (Anthropic) написаны, но не прогонялись (не установлены / нет ключа).

## Запуск (Windows, 3 команды)
Первая настройка один раз — см. [docs/HANDOFF.md](docs/HANDOFF.md). Затем в двух терминалах:
```
# 1) бэкенд, из корня репозитория
.venv\Scripts\python -m uvicorn app.main:app --reload
# 2) фронтенд, из frontend\
npm run dev
# 3) открыть в браузере
http://localhost:5173
```
Демо-файлы для перетаскивания: `eval\cases\demo-001\` (`receipt.png` → «Чек», `chat.txt` → «Переписка»).

Режим без бэкенда (для жюри): в `frontend\` — `set VITE_API_MODE=mock && npm run dev`.

## Инварианты (нарушать нельзя)
LLM возвращает только значения и `line_ids`; текст и координаты копирует код. Правовые нормы — только из `rules/legal_refs.json` (заглушки). Поле попадает в претензию лишь при `confirmed_by_user=true`. Guard блокирует экспорт при любом числе или дате вне подтверждённых фактов и дат событий.
