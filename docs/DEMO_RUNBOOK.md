## Лестница запасных вариантов
Правило: переход вниз по ступени — решение ведущего за 10 секунд. Рассказывать зрителям честно, что именно показываем.

1. **Живой.** Бэкенд + фронтенд, загрузка `demo-001` или нового синтетического чека, живой OCR и/или LLM (режимы `auto` / `openai`, когда они подключены и проверены). Использовать только если в T-60 прогон был зелёным и есть интернет (для OpenAI). В режиме с внешним провайдером текст чека уходит наружу: только синтетика.
2. **Фикстура (`auto` с известным демо-чеком).** Известный sha256 демо-чека берётся из офлайн-фикстур, интернет и ключ не нужны, результат детерминирован. Говорить честно: «OCR и извлечение для этого чека из заготовленных фикстур» (в UI есть плашка источника). Не выдавать фикстуры за живой OCR или ответ модели.
3. **Mock-статика.** `frontend/dist-mock/` на любом статическом сервере (`python3 -m http.server 8080` из папки, либо `npm run preview:mock`). Бэкенд не нужен, все данные синтетические, DOCX — заглушка. Подробности и ограничения: `docs/HANDOFF.md` («Статическая mock-сборка»). Не нажимать F5 на внутренних страницах, начинать с главной. Открытие двойным кликом (`file://`) пока не поддерживается.
4. **Запись.** Видео 70–90 с, на паузе в плеере, ведущий комментирует вживую. Это последняя ступень, готовится заранее.

Триггеры перехода вниз: не поднялся сервер за 2 минуты, ошибка на загрузке, нет интернета для живого режима, не подключается ноутбук, зависание больше 15 секунд на сцене.

## Типовые поломки
| Симптом | Действие |
| --- | --- |
| Порт 5173 или 8000 занят | `vite` выберет другой порт и покажет в выводе; для бэкенда указать `--port`, но тогда поправить прокси в `frontend/vite.config.ts`; иначе ступень 3 |
| «Не найдено» / пустой результат на `demo-001` | Проверить, что `receipt.png` тот самый (sha256 начинается с `eeef4d42540c`), не перегенерированный |
| Нет интернета | Ступень 2 или 3 (шрифт Inter подставится системным, функции не страдают) |
| Белая страница на `dist-mock` | Открыто не через сервер или не из корня; перезапустить сервер из папки `dist-mock/` |
| Guard блокирует экспорт | Это штатное поведение (число или дата вне подтверждённых фактов): подтвердить поля; можно показать как фичу |
