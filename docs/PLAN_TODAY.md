4. Сначала прогнать на OCR + **запасном экстракторе** (см. блок 2, путь Б) или на живом LLM, если есть ключ. Показать пользователю цифры.

**Готово, когда:** `python eval/run_eval.py` одной командой выдаёт честную таблицу, даже скромную (например, сумма 70%, это нормально и лучше выдуманных 99%).
