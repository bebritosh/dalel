## Инварианты (красные линии, нарушать нельзя)
1. LLM возвращает только значения и `line_ids`. Текст строк и bbox копирует код из `OcrLine`.
2. Каждое число и дата в претензии = подтверждённый факт или дата события. Иначе экспорт блокируется (422 + список расхождений).
3. Правовые нормы только из `rules/legal_refs.json` (заглушки `unverified`, без выдуманных статей). В тексте — «[норма уточняется юристом]».
4. Поле попадает в претензию только при `confirmed_by_user = true`.
5. `*.layout.json` (разметка генератора) и `handmade_*` (ручной ответ) нельзя выдавать за реальный OCR/ответ модели. Содержимое документов не логируется; имена файлов на диске — только uuid.

## Что СДЕЛАНО (с файлами)
**Бэкенд — эндпоинты** (`app/api/`, подключены в `app/main.py`):
- `POST /cases`, `GET /cases/{id}`, `DELETE /cases/{id}` — `cases.py`.
- `POST /cases/{id}/documents`, `GET /cases/{id}/documents/{doc_id}/lines`, `/file` — `documents.py`.
- `POST /cases/{id}/extract` — `extract.py`; `PATCH /facts/{id}` — `facts.py`.
- `GET /cases/{id}/timeline | /missing | /checks` — `analysis.py`.
- `POST /cases/{id}/claim`, `GET /cases/{id}/export?format=docx`, `POST /cases/{id}/mark-sent` — `claim.py`.

**Модели** (`app/models/tables.py`): `Case, Document(+ocr_source, extract_source), OcrLine, Fact(+grounded), Event, MissingItem, Claim`.

**Извлечение** (`app/services/extract/`): интерфейс `LlmProvider` + провайдеры `FixtureProvider`, `LiveProvider` (Anthropic, httpx), `OpenAiProvider` (httpx, strict json_schema), `RuleBasedProvider` (регулярки). `LLM_MODE = fixture|live|openai|rules|auto`; `auto` = известный sha → фикстуры офлайн, иначе живой путь. Реальные ответы сохраняются как `eval/fixtures/{sha}.json`. Grounding — `grounding.py`, нормализация чисел/дат — `normalize.py`.

**OCR** (`app/services/ocr/`): `OcrEngine` + `FixtureOcrEngine` + `TesseractEngine`; предобработка (`preprocess.py`, апскейл 1.5×), PDF текст/растер (`pdf.py`). `OCR_ENGINE = fixture|tesseract|auto`.

**Проверки/хронология/недостающее**: `validate.py` (V1–V4, `rules/validation.yaml`), `timeline.py` (события + факты), `missing.py` (M1–M5, `rules/missing_evidence.yaml`), чат — `chat.py` (WhatsApp txt).

**Претензия/guard/экспорт**: `claim.py` (контекст только из подтверждённых фактов + событий, нормы из `rules/legal_refs.json`), `claim_guard.py` (числа/даты вне разрешённых → блок), `export.py` (DOCX через `templates/claim.docx`), `scripts/make_claim_template.py`.

**Eval** (`eval/`): `scripts/make_synthetic.py` (9 дел), `eval/cases/case-001..009` (чек+чат), `eval/gold.json`, `eval/run_eval.py`, снапшоты в `eval/results/`.

**Фронтенд** (`frontend/`): три экрана (`UploadPage/ReviewPage/ClaimPage`), `HashRouter` (`App.tsx`), EN по умолчанию (`i18n/index.ts`), consent-чекбокс, `DeleteCaseButton`, `ProvenanceBadge`, кликабельные суммы/даты + подсветка bbox, mock-сборка (`vite.config.ts`, `npm run build:mock` → `dist-mock/`). Провайдер типов синхронизирован с бэкендом (`api/types.ts`).

**Тесты** (`tests/`): `test_cases, test_documents, test_guard, test_normalize, test_pipeline, test_extract_providers, test_eval_metrics` — **50 passed** (сверено локально 25.11).

**Документы**: `README.md`, `CLAUDE.md`, `docs/HANDOFF.md, DECISIONS.md, PLAN_TODAY.md, PITCH.md, QA.md, SLIDES_UPDATE.md, DEMO_RUNBOOK.md, DEMO_VIDEO.md, ORGANIZERS_EMAIL.md, LAWYER_QUESTIONS.md`, `docs/slides-assets/`.
