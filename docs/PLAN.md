> Конструктор доказательной претензии по некачественному товару (Казахстан). Питч 29 ноября. На демо — только синтетические данные.

## Красные линии (нельзя нарушать ни в одной задаче)
1. LLM возвращает только значения и `line_ids`. Текст строк и координаты копирует код.
2. Число/дата попадают в претензию только если это подтверждённый факт или дата события. Иначе guard блокирует экспорт (422).
3. Правовые нормы — только из `rules/legal_refs.json`. Модель их не пишет.
4. Поле идёт в претензию только при `confirmed_by_user=true`.
5. Фикстуры (`*.layout.json`, `handmade_*`) нельзя выдавать за реальный OCR/ответ модели. `.env` и реальные данные не коммитить.

### 1. Проверить DOCX в настоящем Word (Windows) — самое важное
Зачем: пользователь видел ошибку «содержимое не удалось прочитать». В коде фикс уже есть (санитизация XML-символов), но в настоящем Word его никто не открывал — у меня нет Word.
Шаги:
1. Запусти бэкенд и фронтенд (см. [HANDOFF.md](HANDOFF.md)).
2. Пройди демо: `eval/cases/demo-001/receipt.png` + `chat.txt` → подтверди поля → «Скачать DOCX».
3. Открой файл в Microsoft Word.
Готово, если: Word открывает без ошибки и без предложения «восстановить».
Если ошибка осталась: приложи сам `.docx` и вытащи из него `word/document.xml` (это zip) — с этим можно искать причину дальше. Текст претензии при этом не трогай.

### 2. PDF-экспорт — поставить LibreOffice
Зачем: сейчас кнопка «Скачать PDF» отдаёт 503 (LibreOffice не установлен) — это ожидаемо, но реального PDF нет.
Шаги:
1. Установи LibreOffice.
2. В `.env` пропиши `SOFFICE_PATH=C:\Program Files\LibreOffice\program\soffice.exe`.
3. Перезапусти бэкенд, нажми «Скачать PDF».
Готово, если: скачивается настоящий PDF. Тест `test_export_pdf_converts_when_soffice_available` перестанет быть skip.
