# DÄLEL
Конструктор доказательств для потребительских споров (Казахстан).
Хакатон SDG Impact 2026, питч 29 ноября, прототип обязателен.

## Правила, которые нельзя нарушать
- Каждое число и дата в претензии совпадают с подтверждённым фактом, иначе экспорт блокируется.
- LLM возвращает только line_ids. Текст и координаты копирует код.
- Правовые нормы берутся из rules/legal_refs.json. Модель их не пишет.
- На демо только синтетические данные, реальные чеки в репозиторий не кладём.

## Стек
Python 3.11+ (используем 3.14), FastAPI, SQLModel + SQLite, Pydantic, PaddleOCR или Tesseract,
docxtpl + LibreOffice, React + Vite + Tailwind.

## Команды
- Бэкенд: uvicorn app.main:app --reload
- Тесты: pytest -q
- Точность: python eval/run_eval.py
- Фронтенд: cd frontend && npm run dev

## Структура
app/api, app/models, app/services (ingest, ocr, extract, validate, timeline, claim, export)
rules/ (missing_evidence.yaml, legal_refs.json), templates/claim.docx, eval/, tests/, frontend/

## Как работать
- Сначала короткий план, потом код. Маленькие коммиты.
- После правок извлечения или проверок прогоняй eval и показывай цифры до и после.
- Новые зависимости только после вопроса.
- Отвечай по-русски, комментарии в коде на английском.

## Правила для продолжения работы
- Инварианты не менять: LLM возвращает только значения и `line_ids`; правовые нормы только из `rules/legal_refs.json`; поле попадает в претензию только при `confirmed_by_user=true`; guard блокирует любое число и дату вне подтверждённых фактов и дат событий.
- Фикстуры `*.layout.json` (разметка генератора) и `handmade_*` (рукописные ответы) нельзя выдавать за результат реального распознавания или ответ модели.
- Перед тем как сказать «готово»: `pytest -q`, и в `frontend/` — `npm run typecheck` и `npm run build`. Красное — не чинить молча, сказать пользователю.
- Новые зависимости — только с вопросом. Крупные изменения — сначала план, потом код.
- Не коммитить `.env`; не трогать `eval/real/`.
- После значимых решений обновлять `docs/PLAN.md` и `docs/DECISIONS.md`.
